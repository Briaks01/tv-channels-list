# Список каналов для «ТВ Каналы»

Репозиторий содержит список российских каналов для приложения
[ТВ Каналы](https://github.com/Briaks01/tv-channels). GitHub Actions
пересобирает список каждые 6 часов. Приложение скачивает список при запуске.

## Содержимое

| Путь | Назначение |
|---|---|
| `channels.m3u` | Список каналов. Приложение скачивает этот файл |
| `logos/` | Логотипы каналов |
| `sources/` | Источники потоков |
| `sources/probe_cache.json` | Результаты проверки потоков из России |
| `tools/` | Скрипты сборки списка |
| `tools/tests/` | Тесты скриптов |
| `.github/workflows/update-channels.yml` | Расписание пересборки |
| `docs/glossary.json` | Глоссарий терминов проекта |

## Формат списка

Файл `channels.m3u` имеет формат M3U:

- под строкой `#EXTINF` стоят одна или несколько ссылок на поток;
- первая ссылка основная, остальные запасные;
- атрибут `x-hls="1"` указывает поток HLS (потоковая передача по HTTP);
- атрибут `x-logo` указывает имя файла в каталоге `logos/`;
- атрибуты `x-mailru` и `x-epg` указывают канал в телепрограмме.

Ссылки с префиксами `okru:`, `vitrina:` и `vkplay:` содержат адрес плеера,
а не поток. Ссылку на поток приложение получает перед запуском. Токены
этих источников действуют от суток до недели.

## Источники потоков

Порядок источников задаёт приоритет:

1. `iptvru.m3u` — копия плейлиста smolnp/IPTVru. Автор удалил оригинал с GitHub.
2. `rutube.m3u` — официальные прямые эфиры каналов на RuTube.
3. `extra.m3u` — потоки Wink и VK Play Live. Их проверяют вручную.
4. `smotret.m3u` — каналы сайта smotret.tv.

Сайт smotret.tv встраивает чужие плееры. Скрипт `tools/smotret.py`
поддерживает плееры RuTube, OK.ru и «Витрины ТВ». Плеер VK Видео без входа
в аккаунт поток не отдаёт.

Скрипт `tools/rutube.py` берёт эфир, только если автор эфира совпадает
с названием канала. Так скрипт отбрасывает ретрансляции посторонних
пользователей.

## Сборка списка

Скрипт `tools/prepare.py` выполняет такие действия:

- проверяет каждую ссылку на поток и отбрасывает нерабочие;
- склеивает один канал из разных источников;
- сортирует ссылки канала по качеству;
- ставит федеральные каналы первыми;
- приводит категории к одному списку;
- скачивает логотипы.

Ссылки канала сортируют так:

1. Прогрессивное видео идёт раньше чересстрочного. Стик чересстрочный
   SD почти не воспроизводит.
2. Большее разрешение идёт раньше.
3. При равном разрешении порядок задаёт источник.

Некоторые мастер-плейлисты не указывают звук в атрибуте CODECS. С ними
ExoPlayer теряет звук и не показывает видео. Скрипт заменяет такой
плейлист ссылкой на сам вариант потока.

Скрипт `tools/epg_ids.py` сопоставляет каналы с телепрограммой tv.mail.ru
и epg.iptvx.one.

### Ручная сборка

Для скриптов нужны Python 3, curl, ffmpeg и ImageMagick. Выполните команды:

```bash
python3 -I tools/smotret.py > sources/smotret.m3u
python3 -I tools/rutube.py sources/iptvru.m3u sources/smotret.m3u > sources/rutube.m3u
python3 -I tools/prepare.py sources/iptvru.m3u sources/rutube.m3u sources/extra.m3u sources/smotret.m3u
python3 -I tools/epg_ids.py sources/iptvru.m3u
```

Запускайте ручную сборку с компьютера в России раз в неделю. Так файл
`sources/probe_cache.json` получает свежие результаты проверки.

### Сборка в GitHub Actions

Workflow `.github/workflows/update-channels.yml` пересобирает список
каждые 6 часов. Запустить его вручную можно на вкладке Actions.

Сервер GitHub стоит за границей. Часть источников отдаёт потоки только
в Россию. Поэтому скрипт запускают с ключом `--ci`. В этом режиме скрипт
сохраняет поток в двух случаях:

- поток работал из России в последние 14 дней;
- ссылку на поток приложение получает на стике.

Если источник отдал меньше 70 % прежних каналов, workflow сохраняет
прежний файл. Если в итоговом списке меньше 300 каналов, workflow список
не публикует.

## Тесты

Тесты проверяют чистую логику скриптов. Сеть им не нужна.

```bash
python3 -I -m unittest discover -s tools/tests
```
